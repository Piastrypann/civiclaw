# CIVICLAW - AI-Powered Legal Assistant

## Project Description
CIVICLAW is an AI-powered web application designed to help individuals understand and analyze basic legal issues quickly and efficiently using the Google Gemini API. It provides risk analysis, relevant legal references, and tactical step-by-step guidance for legal problem-solving.

## Key Features
* Automated AI-driven legal case analysis.
* Interactive and user-friendly interface built with Streamlit.
* Direct integration with the Gemini API to generate reliable legal insights.

## How to Run Locally
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
