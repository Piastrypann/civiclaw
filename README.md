# CIVICLAW — Autonomous Legal Navigation Agent

CIVICLAW is an AI-powered legal intelligence agent designed to assist users in navigating complex legal situations, identifying potential violations, mapping statutory provisions, and providing tactical action plans.

---

## 🛠️ Tech Stack & Google Infrastructure
- **Core AI Model:** Gemini Flash via `@google/genai` SDK
- **Frontend / UI:** Streamlit (Python)
- **Deployment & Cloud Infrastructure:** Google Cloud Run / Google Cloud Shell Environment
- **Data Format:** Structured JSON Schema Enforcement

---

## 🚀 Spin-up Instructions (Local Setup)

### 1. Prerequisites
- Python 3.10 or higher
- Gemini API Key from Google AI Studio

### 2. Installation & Run
```bash
git clone https://github.com/Piastrypann/civiclaw.git
cd civiclaw
pip install -r requirements.txt
streamlit run app.py
'''
